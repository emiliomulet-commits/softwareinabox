Écoconception des serveurs et du stockage

Depuis 2020, aucun serveur ni système de stockage de données ne peut être vendu dans l'UE sans respecter des exigences d'efficacité de l'alimentation, de consommation au repos, d'effacement sécurisé, de micrologiciel et d'information sur les matériaux. Le texte est en révision et, en parallèle, les centres de données déclarent déjà leur consommation et auront une étiquette A–G.

Le règlement de 2019 continue de s'appliquer tel quel : la révision n'est pas encore adoptée. La nouveauté de 2026 concerne surtout les exploitants de centres de données, pas le produit.

Écoconception ou ESPR

L'ESPR (règlement 2024/1781) remplace la directive de 2009. Les révisions avancées, comme celle-ci, peuvent encore être publiées sur l'ancienne base si elles sont prêtes fin 2026. Le plan de travail ESPR d'avril 2025 donne la priorité à l'acier, aux textiles et à d'autres produits ; les serveurs suivent leur propre voie.

Belgique

Les centres de données en Belgique

Cadre

  • Pas de loi spécifique : permis régionaux.
  • Elia crée une catégorie « data centre » avec une capacité maximale ; la CREG modifie le code de raccordement (« use it or lose it », 29-1-2026).
  • La Flandre propose de placer les centres de données en fin de file ; la Wallonie recueille les rapports EED.

Situation

En Belgique, le goulot d'étranglement est le réseau, pas un régime propre aux centres de données.

Questions fréquentes

Qu'exige le règlement écoconception pour les serveurs ?

Rendement de l'alimentation, limites de consommation au repos, effacement sécurisé des données, mises à jour du micrologiciel et information sur les matériaux. Il s'applique depuis le 1-3-2020 aux serveurs et produits de stockage en ligne.

Qui doit respecter le règlement écoconception des serveurs ?

Le fabricant, l'importateur ou le mandataire qui met le produit sur le marché de l'UE, avec marquage CE et documentation technique.

Quelles obligations d'efficacité pour les centres de données ?

Ceux de 500 kW ou plus déclarent chaque année leur performance énergétique dans la base de données européenne ; le prochain rapport est dû le 15-5-2027, et la Commission prépare une étiquette d'efficacité A–G.
