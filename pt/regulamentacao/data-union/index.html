Estratégia da União de Dados

A Comissão passa de fazer regras a obter resultados: mais dados de qualidade para a IA, menos regras e mais claras, e uma política aberta mas firme nos fluxos internacionais de dados. As suas peças são os laboratórios de dados, os espaços comuns de dados, o Omnibus Digital e a CADA.

É uma comunicação política, não uma norma: não cria obrigações por si só. Chega às empresas através das propostas legislativas, dos concursos e das orientações que a desenvolvem.

Os três pilares

Pilares da Estratégia
PilarAções principais
1 · Alargar o acesso a dados para a IALaboratórios de dados; espaços comuns de dados com apoio continuado e o Simpl como middleware de interoperabilidade; CADA; conjuntos de dados de elevado valor alargados a dados jurídicos, judiciais e administrativos; orientações e normas sobre dados sintéticos e partilha de dados
2 · Simplificar as regras de dadosOmnibus Digital: consolidação no Data Act, reforma focada do RGPD, cookies; apoio à aplicação do Data Act com cláusulas-tipo, cláusulas cloud normalizadas, orientações e serviço de apoio
3 · Salvaguardar a soberania de dadosFluxos transfronteiriços justos, proteção de dados não pessoais sensíveis, ligação a ecossistemas de países afins e mais voz da UE no G7, no G20 e na OCDE
Pilar 1

Laboratórios de dados

Centros operacionais que dão às empresas e aos investigadores acesso a conjuntos de dados diversos e a serviços para lhes aplicar IA. Os primeiros nascem dentro das Fábricas de IA.

O que oferecem

  • Partilha de dados de várias fontes, compatível com a concorrência
  • Limpeza, normalização, curadoria e etiquetagem
  • Anonimização e geração de dados sintéticos
  • Orientação regulatória e formação
  • Ponte entre os espaços de dados e o ecossistema de IA

O que não são

Não substituem os portais de dados abertos nem os espaços de dados: complementam-nos. Os espaços de dados ordenam a disponibilidade do dado; os laboratórios convertem-no num recurso pronto para treinar, testar ou implantar IA. Também não são salas seguras para dados protegidos, como o acesso seguro a microdados do INE.

Pilar 2 · Omnibus Digital

A consolidação no Data Act

Consolidação das normas de dados
Norma atualO que aconteceria
Data Governance Act (2022/868)É revogado. A intermediação de dados e o altruísmo passam para o Data Act; o registo de intermediários torna-se voluntário e a separação jurídica passa a funcional
Diretiva dos dados abertos (2019/1024)É revogada; a reutilização de dados do setor público junta-se às regras do DGA sobre dados protegidos num único capítulo. Poderiam cobrar-se taxas mais elevadas a empresas muito grandes
Livre circulação de dados não pessoais (2018/1807)É revogado, salvo a proibição de requisitos injustificados de localização, que passa para o Data Act
Data Act (2023/2854)Torna-se a norma central da economia dos dados, com ajustes próprios (segredos comerciais, dados B2G só em emergências)

A sociedade civil (EDRi, Open Future) critica que a intermediação passe a ser voluntária e a mudança nas taxas dos dados abertos. É proposta, não direito vigente.

Pilar 3

Uma abordagem aberta mas firme

Instrumentos

  • Orientações para avaliar o tratamento justo dos dados e empresas da UE em países terceiros
  • Caixa de ferramentas contra a localização injustificada, a exclusão, as garantias fracas e a fuga de dados
  • Medidas específicas para dados não pessoais sensíveis
  • Possibilidade de recusar a partilha de dados quando houver risco elevado de fuga de segredos comerciais para países terceiros

A consulta de 2026

Entre 8 de julho e 8 de setembro de 2026, a Comissão perguntou pelas dependências de dados, pelas barreiras ao acesso a dados em países terceiros e pelos riscos de acesso de países terceiros a dados sensíveis. A consulta liga-se ao pacote de soberania tecnológica de 3 de junho, onde foi apresentada a CADA.

Portugal

Como a estratégia chega a Portugal

Governação de dados

  • O DL 2/2025 executa o Regulamento de Governação de Dados.
  • Para o Data Act ainda não há autoridade designada.
  • Na saúde, a SPMS prepara o acesso secundário (HealthData@PT); o INE dá acesso seguro a microdados para investigação.

Espaços de dados

Portugal participa nos espaços europeus através de centros de investigação e da Agenda Nacional de IA (RCM 2/2026). Para as empresas, o essencial é preparar dados e contratos para os espaços setoriais.
