# Software in a Box — Diseño / Prototipo (REFERENCIA)

Prototipo visual y de contenido de la web de **COGNITIV** (Software in a Box) construido como Design Components (`.dc.html`). 

> **No es la web de producción.** La web pública es el port a React/TanStack (repo aparte). Este repo es la **fuente de diseño, copy y casos** y sirve de respaldo.

## Contenido
- `SIAB-Inicio.dc.html` — home
- `SIAB-COGNITIV.dc.html` — página de producto (arquitectura CORE·VAULT·HUB·NEXUS·TRACE)
- `SIAB-Servidores.dc.html` — catálogo Lenovo ThinkSystem (10 modelos, filtros, tabla comparativa, servicios)
- `SIAB-Casos-Exito.dc.html` — índice de casos de éxito
- `SIAB-Caso-Industria/Finanzas/Legal.dc.html` — casos de uso con hero "mini-vídeo", infografías y métricas
- `SIAB-Bloque-1..5.dc.html` — los 30 argumentos de venta (5 bloques) con infografías animadas
- `SIAB-Contacto.dc.html` — formulario (FormSubmit → emilio.mulet@softwareinabox.eu)
- `index.html` — entrada que abre la home
- `assets/` — fotos de servidores Lenovo y de casos de éxito
- `data-argumentos.json` — los 30 argumentos en JSON (texto fuente)
- `SEO-JSON-LD-COGNITIV.html`, `sitemap.xml`, `robots.txt` — recursos SEO para el repo React

## Cómo abrirlo
Los `.dc.html` necesitan `support.js` (incluido). Para verlo localmente, sirve la carpeta con cualquier servidor estático y abre `index.html`.
